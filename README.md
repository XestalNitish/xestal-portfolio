## 🎨 Claymorphism UI Aesthetics

This portfolio utilizes modern **Claymorphism** design principles:
- **Soft Organic 3D Shapes**: Tactile cards with `border-radius: 28px` and double-layered ambient shadows.
- **Dual-Layer Shadows**: Inset highlights paired with outer diffusion for an inflated, tactile pillowy feel.
- **Pastel Cyber Palette**: Vibrant gradients transitioning through Violet (`#7C3AED`), Electric Blue (`#3B82F6`), and Rose Pink (`#EC4899`).
- **Interactive Feedback**: Dynamic transform lifts, micro-interactions, and responsive layout across desktop and mobile.

## 🛠️ Quick Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/XestalNitish/portfolio.git
   cd portfolio
   ```

2. **Create a virtual environment:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Streamlit application:**
   ```bash
   streamlit run app.py
   ```

---

## ☁️ Deploy to Streamlit Community Cloud in 2 Minutes

1. Push this folder to your GitHub account (e.g. `https://github.com/XestalNitish/portfolio`).
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Click **"New app"**.
4. Select your repository: `XestalNitish/portfolio`.
5. Set Main file path: `app.py`.
6. Click **"Deploy!"** 🎉
